## 🧭 Overview

This is my personal portfolio — a single-page site covering who I am, what I've built, and how to reach me. It brings together projects spanning Java, SQL, database design, and front-end web development, along with my professional certifications.

---

## ✨ Sections

- **Hero** — Introduction with a quick snapshot of projects and certifications
- **About** — A short bio and photo
- **Skills** — Languages, core concepts, and tools I work with
- **Projects** — Detailed write-ups of major academic and personal projects, each linked to its GitHub repository
- **Certificates** — Professional certifications completed
- **Contact** — Direct links to email, GitHub, and LinkedIn
